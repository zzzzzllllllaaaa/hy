因为单条目内容过多，工具栏会离编辑内容很远，很不舒服，所以可以通过自定义 CSS 和少量 JavaScript，让工具栏变成“悬浮式”，即工具栏始终固定在屏幕顶部，或者动态跟随光标的位置。

#### 实现悬浮工具栏的步骤：
在 TiddlyWiki 中，您可以通过添加样式和脚本来自定义工具栏的行为：

1. **添加 CSS：**
   - 打开 TiddlyWiki，创建一个新的 tiddler（即条目），设置 `Tag` 为 `$:/tags/Stylesheet`。
   - 在 tiddler 中粘贴以下代码：

     ```css
     .tc-editor-toolbar {
         position: sticky;
         top: 0;
         z-index: 1000;
         background: white;
         border-bottom: 1px solid #ddd;
         padding: 5px;
     }
     ```

   - 保存后，工具栏将固定在编辑器的顶部，即便滚动页面也不会消失。
